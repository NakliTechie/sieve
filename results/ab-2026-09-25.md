# djev vs GLiNER2.5-Decide — A/B with an option-order test (2026-09-25)

**Setup.** Same rows, same questions, same options, same information for both: question name + options only (no
customer rules, no examples, no calibration). djev = `/v1/systemone` on one Cloud Run RTX PRO 6000 (us-central1),
called from India. GLiNER = `fastino/GLiNER2.5-Decide` (340M, Apache-2.0) on this Mac's GPU (Apple MPS), local.
Rows: all 16 fastino/fast-decisions domains with single-choice questions (1,600 rows, 2,600 questions; multi-choice
questions dropped) and the held-out rows of four stand-in customers (built from public data, see
`pipeline/samples.py`). Each row ran four times: original option order, the same again, reversed, shuffled.
Harness: `pipeline/ab.py`; raw rows in `~/.djev/ab/full/`.

**Read this first.**
- On the public benchmark GLiNER is ahead: **67.3 % vs 62.6 %** (2,600 questions; the gap is about 3.5 standard
  errors). It wins 14 of 16 domains in the original order; djev wins review sentiment and sports recaps.
- On the stand-in customers djev is ahead on helpdesk (+7 pts, 234 questions) and shop (+8 pts, 72 questions). Neither gap
  is statistically solid at these sizes. Both datasets are synthetic.
- **Option order matters for djev, not for GLiNER.** djev changes 11.6 % of answers when asked the same thing twice
  (it randomises its answer slots per call), and 25.1 % when the options are reversed. That is about 13 points of real
  order effect above its own noise. GLiNER is deterministic (0 %) and flips 3.1 % on reversal. Neither model prefers
  the first or last option (within 2 points of the right-answer rate); order makes djev *unstable*, not biased.
- Speed is a draw per call: djev 122 ms on the server (404 ms round trip from India), GLiNER 140 ms on a laptop.
  djev throughput here: 7,744 calls in 389 s at 8 parallel callers (about 20 calls/s, about $0.045 per 1,000 calls
  while the GPU is busy). GLiNER needs no GPU; its cost on a server was not measured.
- Fastino publishes 60.2 % (GLiNER) and 57.6 % ("JevK5") on this benchmark. Our numbers are higher for both because we
  drop multi-choice questions, and the files hold 100 rows per domain, not the 300 the card states.

15488 scored calls, 0 errors. Accuracy is exact match per question.
