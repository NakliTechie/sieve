# Hinglish: stock vs trained, and what code-mixing costs (2026-09-26)

**Setup.** The same harness and rules as `results/stock-vs-trained-2026-09-26.md`: a fixed test set per dataset,
stock models with no labels, and trained models at 5 / 10 / 20 / 50 / all labels per option.
- **Hinglish-TOP:** human-written code-switched assistant queries, Google Research, Apache-2.0 (reported, arXiv
  2211.07514). **hinglish-top-en** is the same 1,000 test queries in their English originals, so the pair
  isolates the cost of code-mixing.
- **hinglish-yt:** 3,190 real YouTube comments, hand-labelled sentiment, CC-BY-4.0; 800 held out.
- **hinglish-retail:** SYNTHETIC e-commerce support intents, MIT; 287 test rows. It is close to messaging-platform traffic but
  is not real, so it is not evidence for a claim.

djev reads ran on the GPU service 08:40–08:50 IST, inside the experiment-1 window. Everything else ran locally.

**Read this first.**
- **Code-mixing costs every usable model 4–6 pts,** with the paired queries: djev@3 80.2 → 76.6 %, Ettin (all labels)
  85.8 → 81.1 %, mmBERT (all labels) 88.8 → 82.8 %. With 50 labels per intent the trained models lose 6–11 pts.
- **GLiNER collapses on Hinglish:** 77.0 % on the English queries, 49.6 % on the same queries code-mixed.
- **Hinglish-TOP needs all labels (~77 per intent) before training wins,** and so do its English originals. The late
  crossover comes from this dataset (57 close intents, few examples each), not from code-mixing.
- **Ettin keeps up with mmBERT on romanized Hinglish** (81.1 vs 82.8 % with all labels), unlike on Devanagari Hindi
  (76.2 vs 84.0 %). The fast model is viable for Latin-script Indian traffic.
- **Real Hinglish sentiment: zero-shot wins at every stage.** djev@3 73.5 %. mmBERT with all 2,390 labels is 67.6 %
  and Ettin 63.6 %. With civil-comments toxicity, this is the second judgement task where training does not pay.
- **Synthetic retail intents:** trained reaches 98.6 % with all labels, against 90.9 % zero-shot. At 50 per intent
  the gain (+2.8) is within about 1.5 standard errors on 287 rows.
