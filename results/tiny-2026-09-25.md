# A 17M model trained in seconds — checked (2026-09-25)

Claim checked: Maxime Rivest's chart (x.com/MaximeRivest/status/2103477572126605604) says Ettin-17M, fine-tuned in 42 s
on banking77, scores 91.5 %, next to Claude Opus 5.5 at 92 % and the Jev API at 79.4 %. Harness: `pipeline/tiny.py`,
one run per setting (seed 0), on this Mac's GPU (Apple MPS). Log: `data/tiny/log.jsonl`.

## banking77 (77 categories, 3,080 test messages)

| Setup | Training rows | Train time | Accuracy |
|---|---|---|---|
| GLiNER2.5-Decide, no training | 0 | – | 69.8 % |
| Ettin-17M, 5 per category | 385 | 9.5 s | 28.5 % |
| Ettin-17M, 10 per category | 770 | 11 s | 54.7 % |
| Ettin-17M, 25 per category | 1,925 | 25 s | 75.7 % |
| Ettin-17M, 50 per category | 3,826 | 57 s | 85.4 % |
| Ettin-17M, all (~130 per category) | 10,003 | **42.6 s** | **90.0 %** |

The headline reproduces within 1.5 points (90.0 % vs 91.5 %, one untuned run). The catch is data: below about
20 labelled examples per category the untrained GLiNER wins; above it the trained 17M model wins.
